# 🧪 SauceDemo QA Manual Testing Project

## 📌 Project Overview

This project contains manual testing of the SauceDemo web application.

The goal is to demonstrate QA skills including:

* Test case design
* Test execution
* Bug reporting
* Test management

---

## 🛠 Tools Used

* TestRail – test case management
* Jira – bug tracking
* GitHub – project documentation

---

## 📋 Test Coverage

The following functionalities were tested:

* Login
* Products page
* Cart functionality
* Checkout process
* Navigation menu

---

## ✅ Test Execution

Test cases were executed manually in TestRail.

Results:

* Passed tests ✔
* Failed tests ❌

---

## 🐞 Bugs Found

### 1. Checkout process allows order completion with empty cart

* Severity: High
* Description: User is able to proceed with checkout process even when cart is empty.

### 2. "All Items" button is not working

* Severity: Medium
* Description: When the user clicks on the “All Items” button from the menu, no action is performed. The page does not change and the button appears unresponsive.

---

## 🔗 Traceability

Failed test cases in TestRail are linked with bugs in Jira.
